## 变更点

- 新建独立分支 `feature/memory-os` 和工作树 `Jotly-memory-os`，原 `life-agent` 工作区保持不动。
- 接入 GRDB 7.11.1，建立 RawEvent、Message、AgentRun、Card、Memory、Entity、ActionLog 等 SQLite 表。
- `LocalStore` 改为 SQLite 兼容门面；首次启动事务迁移 `jotly_store.json`，原 JSON 保留作回退。
- 新输入生成 RawEvent、Message、AgentRun 和 Card 投影；删除 Card 不删除 RawEvent、Message 或 Memory。
- 工具执行写入 ActionLog；`memory.save` 写入 MemoryItem 并关联来源消息和卡片。
- 补充 Memory OS 架构与分阶段迁移文档。

## 验证结果

- 通用 iOS `xcodebuild` 构建通过。
- 已核对原工作区仍处于 `life-agent`，未被切分支或覆盖。
