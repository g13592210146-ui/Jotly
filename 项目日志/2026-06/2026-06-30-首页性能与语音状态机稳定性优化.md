# 2026-06-30 首页性能与语音状态机稳定性优化

## 修改文件
- `Jotly/JotlyHomeViewModel.swift`
- `Jotly/JotlyLocalStore.swift`

## 修复问题
- 右滑删除卡顿：删除主卡及子卡时从多次全量 JSON 读写改为一次批量删除，减少主线程 IO 和数组多次刷新。
- 首页刷新偏重：`displayedCards` 从每次渲染即时 filter 改为 `cards` / `selectedCategory` 变化时派生更新，降低 SwiftUI 列表刷新成本。
- Store 变更风暴：`.jotlyStoreDidChange` 改为短延迟合并刷新，避免连续写盘时多次触发首页全量 reload。
- 长按语音不稳定 / 左滑取消竞态：给每轮语音录制增加 session ID，旧的异步 start / stop 任务不能再回写当前状态。
- 左滑取消重复 teardown：提前释放但 ASR 尚未开始录制时也会立即取消底层 ASR；`cancelSelectedASRService()` 增加重入保护。

## 保持不变
- 没有修改模型提示词、工具调用逻辑、卡片业务判断和 UI 交互语义。
