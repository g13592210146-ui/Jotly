# 2026-06-16 语音识别 Provider 测试分支

## 背景

当前分支是 `feature/mimo-asr`，用于集中测试语音识别 Provider，不影响主分支的输入框版本。

## 本次调整

- 顶部新增语音识别服务切换：`Apple`、`MIMO`、`豆包`、`阿里`
- ViewModel 从直接绑定 `MimoASRService` 改为根据当前 Provider 分发 start/stop/cancel
- MIMO 改为录音期间只缓存音频，松手后一次性提交完整 WAV 给 MIMO API
- 新增 `CloudASRServices.swift`，预留豆包和阿里云服务入口

## MIMO 策略调整原因

之前的 MIMO 流式方案每隔约 1.5 秒把“从开头到当前”的完整音频重新发送给模型。模型每次都会重新识别前文，客户端再追加 SSE delta，容易出现同一句话重复多次的问题。

当前采用更稳定的测试策略：

1. 录音时只做音量动画和音频缓存
2. 松手后只发一次完整音频
3. 用最终结果生成卡片

这牺牲了 MIMO 的实时文字体验，但能先验证最终识别质量。
