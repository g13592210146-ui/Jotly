# 2026-06-12 语音交互细调 - 三球弧形与挂住模式

## 本次目标

在不大改首页主体结构的前提下，细调底部语音交互：

- 左右取消 / 编辑阈值更对称，避免轻微右移误触编辑
- 底部液体球更跟手，覆盖拇指位置
- 新增“上滑挂住”模式，允许持续说话，不必一直长按
- 底部操作改成三球弧形：取消 / 挂住 / 编辑

## 已完成

### 1. 手势收紧

- 将左右判定阈值收紧到更克制的区间
- 中间默认态更稳定
- 上滑时优先进入挂住意图，减少轻微横向抖动带来的误触

### 2. 挂住模式

- 在 `VoiceReleaseAction` 中新增 `hold`
- 新增 `isVoiceHoldLocked`
- 长按后上滑可进入挂住
- 挂住后录音继续，不需要再保持手指按住屏幕
- 中间球支持“挂住 / 停止”切换

### 3. 三球弧形 UI

- 底部操作改成左中右三球弧形
- 左侧：取消
- 中间：挂住 / 停止
- 右侧：编辑
- 提示文案上移到球组附近

### 4. 液体跟手

- 调整 `LiquidConnectorCanvas`
- 增大液体主体与拉伸半径
- 提高拖拽时的跟手感，让视觉更贴近拇指轨迹

## 验证

- 使用 `xcodebuild` 编译通过
- 当前版本未做模拟器真机行为回放，后续建议在 Xcode / 真机上继续确认：
  - 三球弧形的视觉比例
  - 上滑挂住的手感
  - 左右取消 / 编辑的触发距离

## 后续建议

- 真机上重点观察上滑挂住是否足够自然
- 如果右侧编辑仍偏敏感，再把左右阈值同步再收一点
- 如需更强的“跟手”效果，可继续微调液体主球的 lead factor 和 drop 半径
