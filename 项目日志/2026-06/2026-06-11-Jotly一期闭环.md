# Jotly 项目日志 2026-06-11

## 目标

完成 AI 语音随手记 App 的第一期闭环：

- 长按语音 -> iOS 本地语音识别实时转写
- 松手生成顶部任务卡片
- DeepSeek 识别生日事件
- 展示 A/B/C 审批选项
- 用户确认后执行本地记录或提醒
- 非生日输入兼容为普通记录，不做复杂业务设计

## 已完成

- 首页重构为任务卡片驱动，不再是原始文本/图片/文件展示页。
- 底部输入区改成三段式：
  - 左侧相机圆按钮
  - 中间语音胶囊
  - 右侧加号圆按钮
- iOS 26+ 使用 `glassEffect`，iOS 18+ 使用 `ultraThinMaterial` 和高光描边做兼容。
- 语音识别已接通系统 `Speech` + `AVAudioEngine`。
- 长按语音浮窗已补：
  - 实时转写展示
  - 左滑取消
  - 右滑编辑
  - 松手发送
- 键盘模式已改成真实文本输入框，点击后会拉起输入法。
- DeepSeek 已接通：
  - `https://api.deepseek.com/chat/completions`
  - 模型：`deepseek-v4-flash`
  - 已做 HTTP 错误可见化
  - 已做 JSON 失败兜底
- 生日主流程已实现：
  - `processing`
  - `waiting_confirmation`
  - `executing`
  - `completed`
  - `failed`
- 本地 JSON 持久化已实现：
  - `RawInput`
  - `MemoryCard`
  - `BirthdayEvent`
  - `ReminderTask`
- 阴历生日支持已补基本数据转换与保存。
- 启动时会恢复最后一张卡片状态。

## 兼容策略

- 生日场景优先走 A/B/C 审批与工具执行。
- 非生日输入不再强行归类为生日，先保存为普通记录。
- 当前不做复杂业务扩展：
  - 不扩展订阅、日记、打卡等其他场景
  - 不做复杂的多任务编排
  - 不做通讯录匹配、礼物推荐、祝福生成

## 当前实现状态

- 代码已通过 `xcodebuild` 编译。
- DeepSeek 外网请求已用系统 `curl` 验证可通，返回 HTTP 200。
- 当前机器的 `CoreSimulatorService` 仍不稳定，所以还没有做完整模拟器 UI 实操验证。
