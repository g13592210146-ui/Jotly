## 修复的问题与变更点

### 1. 扩充 `AgentDebugTurn` 结构以存放明细 Token 指标
- **修改**：在 [JotlyModels.swift](file:///Users/gaoxingchen/Documents/Jotly/Jotly/Jotly/JotlyModels.swift) 中为调试轮次数据实体 `AgentDebugTurn` 增加了四个整型可空属性：
  - `promptTokens: Int?`
  - `completionTokens: Int?`
  - `promptCacheHitTokens: Int?`
  - `promptCacheMissTokens: Int?`

### 2. 在 ViewModel 侧解析并填充明细 Token 数据
- **修改**：在 [JotlyHomeViewModel.swift](file:///Users/gaoxingchen/Documents/Jotly/Jotly/Jotly/JotlyHomeViewModel.swift) 的 `updateDebugTurn` 中，解析模型返回的 `AgentModelUsage` 时，不仅格式化了汇总的 `tokenUsageText`，还提取了明细：输入 Token、输出 Token、缓存命中与未命中的具体数值，分别填充到当前 Turn 的明细属性中。

### 3. 在调试对话卡片上实现 Dashboard 化的可视化指标组件
- **修改**：在 [JotlyHomeScreenSections.swift](file:///Users/gaoxingchen/Documents/Jotly/Jotly/Jotly/JotlyHomeScreenSections.swift) 的 `DebugConversationRow` 卡片中，废弃了原有的单行普通文本回显。
- **UI 设计**：新增了 `tokenMetricCard(title:value:color:)` 辅助视图。当 Turn 中含有 Token 统计数据时，会将其渲染成一个 **横向四列的 Dashboard 徽章格**：
  - **输入 Token**：蓝色背景 + 蓝色数字
  - **输出 Token**：紫色背景 + 紫色数字
  - **缓存命中**：绿色背景 + 绿色数字
  - **缓存未命中**：橙色背景 + 橙色数字
  这让大模型响应后产生的 Token 消耗和缓存命中结果在调试卡片上瞬间一目了然，呈现非常 premium 的可视化界面。
